# 建筑与城市规划作品集

本作品集收录了本人本科阶段完成的建筑与城市规划设计作品，以及一份量化研究报告，展示我从问题识别、需求分析到功能组织、空间设计与方案表达的思考过程。

作为游戏策划求职材料的补充，这部分作品主要用于呈现我的分析方法、空间思维和设计表达能力，并说明这些能力与游戏设计工作的关联。

## 作品集内容

- **建筑设计作品**：围绕使用需求与场地条件，进行功能配置、空间组织、流线设计及视觉表达。
- **城市规划相关作品**：从更大尺度分析空间关系、功能布局与使用场景，处理不同需求之间的协调与取舍。
- **量化研究报告**：通过数据整理与分析，为问题判断和研究结论提供依据。

## 从建筑设计到游戏设计

“建筑是空间的游戏。”对我而言，这句话强调的是：设计不仅要形成可观看的结果，更要组织人在其中的行动、选择与感受。

建筑设计需要思考使用者如何进入空间、识别方向、抵达目标，以及不同功能如何共同服务于使用体验。游戏设计同样需要关注玩家如何理解环境、作出决策，并在规则与反馈中推进体验。

因此，我可以将建筑与规划学习中形成的以下方法迁移到游戏策划工作中：

- **从需求出发定义问题**，先明确服务对象与体验目标，再选择设计手段。
- **在约束下比较方案**，理解功能之间的关系，并对优先级与取舍作出解释。
- **通过空间组织行为**，关注路径、节点、视线和层次对体验的影响。
- **将抽象想法转化为可讨论的方案**，通过图纸、模型、数据与文字清晰表达设计逻辑。
