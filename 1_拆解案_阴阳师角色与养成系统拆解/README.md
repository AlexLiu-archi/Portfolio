# 《阴阳师》角色与养成系统拆解

这是一份围绕角色获取、式神培养与御魂构筑的游戏系统拆解。我希望通过它说明：角色如何从“被获取”转化为“可用的阵容能力”，以及不同养成机制如何组织玩家目标、资源投入和长期追求。

## 我完成了什么

- **四个主体章节**：游戏概述、式神系统、式神养成、御魂系统，总共万余字。含13张表格及37个嵌入图片对象，涵盖实机截图、流程图和分析图。
- **基础育成的实测与建模**：连续记录二星1级至六星40级的分阶段资源消耗，建立从零准备白蛋的递归模型，区分角色本体、素材链和现有库存对新增成本的影响。
- **御魂培养与资源循环分析**：梳理获取、筛选、阶段强化、配装、管理及处置流程，比较不同强化材料的成本，并分析随机产出、定向兑换与资源回流的关系。
- **图文表达**：结合游戏界面说明规则，用系统关系图与流程图呈现机制之间的交互，帮助不熟悉游戏的读者理解分析对象。

## 我的思路

**从规则追到设计作用。**不止描述功能入口，还分析觉醒为什么构成阶段节点、重复获取如何保留培养价值，以及一键育成如何减少长线积累后的重复操作。

**从单体培养转向系统关系。**将角色获取、技能材料、御魂配置与阵容需求连接起来，讨论培养优先级、资源复用和机会成本。

**用计算约束判断。**列明模型假设与费用边界，将实测新增投入与从零培养需求分开；对技能随机升级、御魂强化节点及配置约束进行量化说明，避免只凭游玩感受下结论。

**同时评价收益与代价。**关注随机成长带来的长期目标，也讨论其不确定性与筛选负担；关注自动整理和搭配工具的效率，也分析规则设置与结果验证的重要性。
