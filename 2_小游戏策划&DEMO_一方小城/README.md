# 一方小城｜轻量城市营造策划与可玩 Demo

《一方小城》是一款浏览器端的轻量城市营造原型。玩家通过 A/B 双卡选择，在城市外围逐格建设，利用功能邻接、住宅组团与公共配套获得积分，并逐步形成自己的城市作品。

本项目重点展示我将玩法构想转化为规则、数值配置和可玩原型，并通过试玩反馈持续迭代的过程。

## 核心玩法

- **A/B 双卡保留：** 使用哪张卡，仅刷新对应卡位，另一张保留，支持跨回合规划。
- **空间组合计分：** 通过功能邻接、2×2 住宅组团、贸易围合和公共配套形成收益。
- **有限纠错：** 每局提供两次撤销和两次跳过，保留布局决策的机会成本。
- **标准与无限模式：** 标准局为 30 次建设；结算后可继续无限营造，后续不再增加积分。
- **随机开局：** 湖泊与固定障碍物在起点周围随机生成，提供不同的接入和绕行选择。

## 主要迭代

- 将三选一整手刷新改为 A/B 双卡保留，降低同时决策的负担。
- 将图标式占位资源调整为卡通 2.5D 建筑，并增加升级和自然区域连接表现。
- 降低住宅供给权重，提高自然与特殊功能的出现机会，补充候选保底。
- 增加撤销、跳过、个人排行榜，并将标准计分与无限创作分离。
- 调整公园模块、道路连接和操作入口，改善地图辨识与操作一致性。

具体设计依据、规则边界和迭代原因见策划案。

## 快速操作

1. 选择 A/B 功能卡。
2. 点击城市外围空地，查看放置预览。
3. 再次点击同一格完成建设。
4. 点击已建地块，可在右侧查看档案并使用撤销。
5. 卡片右下角可使用跳过；按 H 可查看规则说明。

支持拖动地图、滚轮缩放，以及 A/B 或数字 1/2 选卡。
